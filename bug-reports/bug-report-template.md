# Шаблон баг-репорта

## Формат баг-репорта

| Поле | Описание | Пример |
|------|----------|--------|
| **ID** | Уникальный идентификатор | BUG-001 |
| **Заголовок** | Краткое описание проблемы | Пароль принимается без спецсимволов |
| **Приоритет** | Critical/High/Medium/Low | High |
| **Серьезность** | Blocker/Critical/Major/Minor | Major |
| **Статус** | New/Open/Fixed/Closed | New |
| **Назначен** | Кому назначен баг | Developer |
| **Создан** | Дата создания | 2024-10-18 |
| **Создатель** | Кто нашел баг | QA Tester |

## Описание
**Краткое описание**: Пароль принимается системой без обязательных спецсимволов

**Шаги воспроизведения**:
1. Открыть форму регистрации
2. Ввести пароль: `Password123` (без спецсимволов)
3. Нажать "Зарегистрироваться"

**Ожидаемый результат**: Система должна отклонить пароль с сообщением об ошибке

**Фактический результат**: Пароль принят, регистрация прошла успешно

**Окружение**:
- Браузер: Chrome 120.0
- ОС: Windows 10
- URL: https://example.com/register

**Дополнительная информация**:
- Скриншот: [приложить скриншот]
- Логи: [приложить логи]

## Примеры баг-репортов

### BUG-001: Пароль без спецсимволов принимается
**Приоритет**: High  
**Серьезность**: Major  
**Описание**: Система принимает пароль `Password123` без спецсимволов, хотя по требованиям нужен минимум 1 спецсимвол

### BUG-002: Email без @ принимается
**Приоритет**: High  
**Серьезность**: Critical  
**Описание**: Система принимает email `userexample.com` без символа @

### BUG-003: Пустое имя пользователя принимается
**Приоритет**: Medium  
**Серьезность**: Major  
**Описание**: Система позволяет зарегистрироваться с пустым полем имени
