# Классы эквивалентности для тестирования регистрации

## 1. ПАРОЛЬ - Классы эквивалентности

### Валидный класс
- **Условие**: Пароль соответствует всем требованиям
- **Критерии**: ≥ 8 символов, ≥ 1 заглавная, ≥ 1 цифра, ≥ 1 спецсимвол
- **Представитель**: `Password123!`
- **Граничные значения**: `Pass12!` (минимум 8 символов)

### Невалидный класс 1: Длина < 8 символов
- **Условие**: Пароль короче 8 символов
- **Представитель**: `Pass1!`
- **Граничные значения**: `Pass1!` (7 символов)

### Невалидный класс 2: Нет заглавных букв
- **Условие**: Пароль ≥ 8 символов, но нет заглавных букв
- **Представитель**: `password123!`
- **Граничные значения**: `password123!`

### Невалидный класс 3: Нет цифр
- **Условие**: Пароль ≥ 8 символов, есть заглавные, но нет цифр
- **Представитель**: `Password!`
- **Граничные значения**: `Password!`

### Невалидный класс 4: Нет спецсимволов
- **Условие**: Пароль ≥ 8 символов, есть заглавные и цифры, но нет спецсимволов
- **Представитель**: `Password123`
- **Граничные значения**: `Password123`

## 2. EMAIL - Классы эквивалентности

### Валидный класс
- **Условие**: Email соответствует стандартному формату
- **Критерии**: Есть @, есть локальная часть, есть домен с TLD
- **Представитель**: `user@example.com`
- **Граничные значения**: `a@b.c` (минимальный валидный)

### Невалидный класс 1: Отсутствует @
- **Условие**: Email без символа @
- **Представитель**: `userexample.com`
- **Граничные значения**: `userexample.com`

### Невалидный класс 2: Отсутствует домен
- **Условие**: Email с @, но без домена
- **Представитель**: `user@`
- **Граничные значения**: `user@`

### Невалидный класс 3: Отсутствует локальная часть
- **Условие**: Email с доменом, но без локальной части
- **Представитель**: `@example.com`
- **Граничные значения**: `@example.com`

### Невалидный класс 4: Пустой email
- **Условие**: Пустое поле email
- **Представитель**: `` (пустая строка)
- **Граничные значения**: `` (пустая строка)

## 3. ИМЯ ПОЛЬЗОВАТЕЛЯ - Классы эквивалентности

### Валидный класс
- **Условие**: Имя не пустое и содержит только допустимые символы
- **Представитель**: `Иван Иванов`
- **Граничные значения**: `А` (минимум 1 символ)

### Невалидный класс 1: Пустое имя
- **Условие**: Пустое поле имени
- **Представитель**: `` (пустая строка)
- **Граничные значения**: `` (пустая строка)

### Невалидный класс 2: Только пробелы
- **Условие**: Имя содержит только пробелы
- **Представитель**: `   `
- **Граничные значения**: ` ` (один пробел)
