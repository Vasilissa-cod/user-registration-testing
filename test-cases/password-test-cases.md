# Тест-кейсы для валидации пароля

## Классы эквивалентности для пароля

### 1. ВАЛИДНЫЙ КЛАСС
**Условие**: Пароль соответствует всем требованиям
- ≥ 8 символов
- ≥ 1 заглавная буква
- ≥ 1 цифра
- ≥ 1 спецсимвол

| ID | Пароль | Ожидаемый результат | Класс эквивалентности |
|---|---|---|---|
| TC_PASS_01 | `Password123!` | ✅ Валидный | Валидный класс |
| TC_PASS_02 | `MyPass@2024` | ✅ Валидный | Валидный класс |
| TC_PASS_03 | `Test#1234` | ✅ Валидный | Валидный класс |
